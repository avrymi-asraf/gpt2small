Input Text String
"The quick brown fox..."
Tokenizer (BPE) [Seq]
Converts text to token IDs (Vocab: 50,257)
Embedding Layer [Seq, 768]
Token Embeddings + Position Embeddings
E = E_{token} + E_{pos}
GPT-2 adds learned positional embeddings to the token embeddings to retain sequence order information.
Final Layer Norm [Seq, 768]
Unembedding (LM Head) [Seq, 50257]
Projects hidden states to vocabulary logits
Softmax [Seq, 50257]
Converts logits to probabilities
P(x_i) = \frac{e^{x_i}}{\sum_{j} e^{x_j}}
Converts the raw output logits into a probability distribution over the vocabulary.
